## 1. Правило «откат внутри силы» — главное

    rsi48 >= 56.3761  И  rsi6 <= 33.7947  ->  LONG
    тейк 1.0 ATR, стоп 3.0 ATR, удержание 48ч — как у банка
    РЕЖИМНЫЙ ГЕЙТ НЕ ПРИМЕНЯТЬ
    дневной фильтр BTC против SMA(50) оставить

### Что придётся тронуть

**а) Признаки.** `src/pullback_bank.py`, функция `features()` считает `atr, rsi2, rsi14, slope,
ret24, rng, volreg, btc24, body, hour`. Ни `rsi6`, ни `rsi48` в ней нет. Добавить две строки:

```python
        rsi6=_rsi(c, 6),
        rsi48=_rsi(c, 48),
```

Проверено: исследовательская функция, на которой правило найдено, — это буквально `PB._rsi`
(`feat2._rsi` возвращает `PB._rsi(c, n)`). Сглаживание одно и то же, пороги переносятся без
искажения.

**б) Обход режимного гейта.** `hourly_signals()` сейчас отбрасывает час, если он не попал в режимный
интервал, и только потом смотрит правила:

```python
        j = bisect.bisect_right(starts, close) - 1
        if j < 0 or not (iv[j][0] <= close < iv[j][1]) or np.isnan(F["atr"][i]):
            continue
        side = iv[j][2]
        if side == "LONG" and btc_down(close):
            continue
        for k, r in enumerate(rules):
```

Нужен флаг у правила. Форма правки:

```python
        if np.isnan(F["atr"][i]):
            continue
        j = bisect.bisect_right(starts, close) - 1
        inside = j >= 0 and iv[j][0] <= close < iv[j][1]
        side = iv[j][2] if inside else None
        down = btc_down(close)
        for k, r in enumerate(rules):
            want = r.get("side", "LONG")
            if not r.get("gateless") and (not inside or side != want):
                continue
            if want == "LONG" and down:
                continue
```

**в) Само правило** в набор:

```python
{"name": "pullback_in_strength", "tp": 1.0, "sl": 3.0, "gateless": True,
 "conds": [("rsi48", ">=", 56.3761), ("rsi6", "<=", 33.7947)]}
```

### Чего правка НЕ касается

Ни одно существующее правило банка не меняется. Гейт для них остаётся как был — новый флаг
`gateless` действует только на новое правило. Геометрия, удержание, размер позиции, все живые
сторожа — без изменений.

## 8. Размер x1.25, когда в одном часе 10+ сигналов

**Что это.** Когда правило срабатывает сразу на многих монетах в один и тот же час, это откат всего
рынка внутри силы — такие сделки лучшие в книге (ВР 87-88%, +0.16..+0.18R, пачка целиком в стопе
почти никогда). Когда в скане часа 10 и больше монет дали сигнал, маржа каждой такой сделки x1.25.

**Где в коде.** `src/pullback_live.py`, `maybe_scan` (строки 133-186): сигналы часа складываются в
`state["watch"]` с полем `close`. После того как скан часа закончен (`len(sc["done"]) ==
len(self.symbols)`, строка 182), n = число наблюдений с этим `close`. Его нужно сохранить в каждое
наблюдение (например `w["burst"] = n`). В `_enter` (строки 247-255) после урезания по `stop_ref`:
`if w.get("burst", 0) >= 10: margin *= 1.25`. Проверка `margin > bal` (строка 256) остаётся после.

**Что меняется по смыслу.** Комментарий в `_enter` (строки 250-251) говорит «never larger than the
setting» — буст делает сделку больше настройки пользователя на 25%. Это осознанное изменение правила,
его нужно подтвердить отдельно.

**Проверки.** Заливка 85%, 10 парных розыгрышей, n по реально открытым сделкам:

    книга без XLM и AAVE   $4398 -> $4666 (+6%)  | при равной просадке $5679 -> $5951 | 10/10, просадка не хуже 10/10
    все 15 монет            $4128 -> $4598 (+11%) | $4923 -> $5264 | 9/10, просадка 11.7% -> 11.8%
    без AAVE, с XLM         $4432 -> $4795 (+8%)  | $6064 -> $6556 | 10/10, просадка не хуже 9/10

Плато при полной заливке: книга 1 выше системы при любом пороге 6-10 и множителе 1.15-1.5; скользящий
выбор по годам лучше в 4 из 5 на обеих книгах. Пороги 7-8 на всех 15 монетах поднимают просадку при
реальной заливке — поэтому порог 10, а не ниже, и множитель 1.25, а не 1.5.

**Чего не обещает.** Выигрыш сидит в 2025-2026 (там пачек 10+ больше всего); в 2022 пачек 10+ не было,
2023-2024 смешанно. Прирост скромный.
